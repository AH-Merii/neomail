# 00 · Cursor n (retired)

The original neomail logo: a geometric lowercase **n** whose right leg is a teal terminal-cursor block (PR #2). It was the main logo in `assets/logo/` until [DEC-2026-10-11-logo](../../../../docs/decisions.md#dec-2026-10-11-logo) adopted variation 05, "Split and statusline", in its place.

The files are kept here unchanged, as they were in `assets/logo/` at retirement:

- the SVG masters, the PNG icons, `logo.txt`, `logo.ans` and the social card;
- `GUIDE.md`, the brand guide that was `assets/logo/README.md`. Its paths still say `assets/logo/`; read them as this folder;
- `src/`, the generator. Its scripts write into their parent folder, so they now rebuild this folder (`cd src`, then the commands in `GUIDE.md`).

Do not use these files for new work. The current logo is in [`../../`](../../README.md).
